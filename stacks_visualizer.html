📚 What is a Stack? LIFO

A stack is a Last-In-First-Out pile — you can only add or remove from the top.

💡 Intuition

A stack of plates: you add a plate on top (push) and take one off the top (pop). The last plate placed is the first one removed — you can't pull from the middle.
push → add on top·pop → remove top·peek → read top
🔒 Keep forever: "Only the top is reachable — Last In, First Out."
Operations: push 3, push 7, push 5, pop, push 9, pop.

stack.push(x);        // add on top
int t = stack.peek();  // read top
stack.pop();          // remove top

↔️ Two Stacks in One Array Space share

Pack two stacks into a single array — one grows from the left, the other from the right.

💡 Intuition

Two diggers, one tunnel: start one stack at the far left (top1 moves right) and the other at the far right (top2 moves left). They only clash if they meet in the middle — until then, both share the same array with zero waste.
stack1: top1 from index 0 →·stack2: top2 from n−1 ←·full when top1+1 == top2
🔒 Keep forever: "Grow from both ends toward the middle — one array, two stacks."

Never forget: top1 starts at −1 (grows +), top2 starts at n (grows −). Overflow only when top1 + 1 == top2.
push1(x){ if (top1+1==top2) overflow; a[++top1]=x; }
push2(x){ if (top1+1==top2) overflow; a[--top2]=x; }

⬇️ Push an Element at the Bottom Recursion

A stack only exposes its top — to insert at the bottom, empty it recursively, place the item, then rebuild.

💡 Intuition

Slip a plate underneath: you can't reach the bottom directly, so lift every plate off (recursion holds them), set the new plate down, then put the others back in the same order. The call stack remembers them for you.
pop all (recurse)→push the new item→push held items back
🔒 Keep forever: "Can't reach the bottom? Recurse to empty it, insert, then unwind."
Stack [1, 2, 3] (top 3). Insert 9 at the bottom → [9, 1, 2, 3].

Never forget: the recursion IS the temporary storage — no extra array needed. Base case: empty stack → push the item.
void insertBottom(stack, x){
  if (stack.isEmpty()){ stack.push(x); return; }
  int t = stack.pop();
  insertBottom(stack, x);
  stack.push(t);   // unwind in original order
}

🔄 Reverse a Stack Recursion

Reverse a stack in place using only stack operations — pop everything, then re-insert each at the bottom.

💡 Intuition

Flip the pile: pop the top and hold it, reverse the rest, then slide that held item to the bottom. Doing this for every element flips the whole stack — the old top ends up at the bottom.
pop top, hold it→reverse the rest→insert held at bottom
🔒 Keep forever: "Reverse = pop each and re-insert it at the bottom."
Stack [1, 2, 3, 4] (top 4) → reversed [4, 3, 2, 1] (top 1).

Press play to reverse the stack.
🐢 🐇
🧠
Never forget: reuses "insert at bottom" — the whole trick is layering two recursions. O(n²) but pure stack ops.
void reverse(stack){
  if (stack.isEmpty()) return;
  int t = stack.pop();
  reverse(stack);
  insertBottom(stack, t);
}

📈 Next Greater Element Monotonic stack

For each element, find the next larger value to its right — one pass with a decreasing stack.

💡 Intuition

Waiting for a taller friend: keep a stack of elements still "waiting" for someone taller. When a bigger number arrives, it resolves everyone shorter on the stack (they found their next-greater), then joins the queue.
while stack top < current → pop & answer = current→push current
🔒 Keep forever: "A bigger arrival resolves every smaller one waiting on the stack."
Array [2, 1, 2, 4, 3] → next greater = [4, 2, 4, -1, -1].
Stack (waiting)
Press play. A larger element resolves the waiting ones.
🐢 🐇
🧠
Never forget: each element is pushed and popped once → O(n). Same skeleton solves next-smaller, stock span, and daily temperatures.
for (int i=0; i<n; i++){
  while (!st.isEmpty() && a[st.peek()] < a[i]) res[st.pop()] = a[i];
  st.push(i);
}  // leftovers have no greater → -1

🏙️ Largest Rectangle in a Histogram Monotonic stack

Find the biggest rectangle fitting under a skyline — a monotonic stack finds each bar's span in O(n).

💡 Intuition

How wide can each bar stretch? a bar can extend left/right until it hits a shorter bar. Keep an increasing stack; when a shorter bar appears, pop the taller ones and compute their rectangle (height × the width they can now claim).
increasing stack of bars→shorter bar? pop & compute area→track max
🔒 Keep forever: "Pop a bar when a shorter one arrives — its width is bounded by both shorter neighbours."
Heights [2, 1, 5, 6, 2, 3] → largest area = 10 (5 & 6, width 2).
Press play. Green shows the winning rectangle span.
🐢 🐇
🧠
Never forget: width = (current index − stack-below − 1). Add a height-0 sentinel at the end to flush the stack.
for (int i=0; i<=n; i++){
  int h = (i==n) ? 0 : height[i];
  while (!st.isEmpty() && height[st.peek()] >= h){
    int top = st.pop();
    int w = st.isEmpty() ? i : i - st.peek() - 1;
    best = max(best, height[top] * w);
  }
  st.push(i);
}

▦ Binary Matrix I — Build Histograms Row heights

To find the largest all-1s rectangle, turn each row into a histogram of consecutive 1s above it.

💡 Intuition

Stacking bricks upward: walk the matrix row by row. For each column, if the cell is 1, the bar grows one taller than the row above; if it's 0, the bar resets to the ground. Each row becomes a skyline of 1-heights.
cell 1 → height += 1·cell 0 → height = 0
🔒 Keep forever: "Each row is a histogram: 1 stacks the bar taller, 0 knocks it to zero."

🧠
Never forget: height[c] = matrix[r][c]==1 ? height[c]+1 : 0. This reduces a 2-D problem to n one-dimensional histograms.
for (int c=0; c<cols; c++)
  height[c] = (matrix[r][c]==1) ? height[c]+1 : 0;

Run the largest-rectangle-in-histogram on every row's heights and keep the global best.

💡 Intuition

Best skyline of all: each row's histogram (from part I) hides its own biggest rectangle. Solve the histogram problem per row and take the maximum across all rows — that's the largest all-1s rectangle in the matrix.
for each row histogram→largest rectangle→track global max

➕ Sum of Subarray Minimums Contribution

Sum the minimum of every subarray by counting, for each element, how many subarrays it dominates.

💡 Intuition

Who rules each subarray? instead of scanning all subarrays, ask: for how many is element a[i] the minimum? That's (distance to previous smaller) × (distance to next smaller). Add a[i] × left × right for every element.
left = span to previous smaller·right = span to next smaller→contribution = a[i]·left·right
🔒 Keep forever: "Each element rules left×right subarrays — sum a[i]·left·right."
Array [3, 1, 2, 4] → sum of subarray minimums = 17.
Press play. Each element's ruling span & contribution.
🐢 🐇
🧠
Never forget: use monotonic stacks to get previous/next smaller in O(n). Break ties consistently (strict one side) to avoid double-counting.
ans += a[i] * (i - prevSmaller[i]) * (nextSmaller[i] - i);
// prevSmaller / nextSmaller found with monotonic stacks

🧹 Remove Adjacent Duplicates Stack cancel

Repeatedly cancel neighbouring equal characters — a stack does it in one pass.

💡 Intuition

Annihilating pairs: push each character; if it matches the top, they cancel — pop instead of push. Whatever remains on the stack is the fully reduced string, with every adjacent duplicate removed (including new ones exposed by removals).
char == top? pop (cancel)/else push
🔒 Keep forever: "Matches the top? cancel it. The stack holds the reduced result."
String "abbaca" → "ca" (b-b cancel, then a-a cancel).

Press play. Equal-to-top characters annihilate.
🐢 🐇
🧠
Never forget: the stack automatically exposes newly-adjacent duplicates after a cancel — one pass, O(n).
for (char c : s){
  if (!st.isEmpty() && st.peek()==c) st.pop(); // cancel
  else st.push(c);
}  // stack bottom→top = answer

🔻 Design a Min Stack Two stacks

Support push, pop, top, and getMin — all in O(1) — using a second stack that tracks the running minimum.

💡 Intuition

A shadow that remembers the smallest: alongside the main stack, keep a "min stack". Each push also pushes the smaller of (new value, current min). The min stack's top is always the minimum of everything currently stored.
push x → minStack.push(min(x, curMin))·getMin = minStack.top
🔒 Keep forever: "Mirror the stack with a running-min stack — getMin is just its top."
Push 5, 3, 7, 2, 8 → getMin tracks the smallest so far.

push(x){ main.push(x); min.push(min.isEmpty()? x : Math.min(x, min.peek())); }
getMin(){ return min.peek(); }
pop(){ main.pop(); min.pop(); }

⚡ Min Stack in O(1) Space Encoding trick

One stack, no extra min stack — encode the old minimum inside the pushed value when a new min appears.

💡 Intuition

Hide a note under the new record: keep a single min variable. When a value smaller than min arrives, push an encoded value 2·x − min (always below the real x) and update min = x. On pop, if the top is below min, it's an encoded marker — the real value is min, and you decode the previous min as 2·min − top.
x < min? push 2x−min, min=x·pop encoded → restore min = 2·min − top
🔒 Keep forever: "Encode the previous min into the pushed value — O(1) space, no second stack."
Push 5, 3, 7, 2 with encoding, then pop to decode the min.
Stack (encoded)
Press play. Watch encoded markers and the min variable.
🐢 🐇
🧠
Never forget: an encoded value is always less than the real x, so "top < min" flags it on pop. O(1) extra space.
push(x){ if (st.isEmpty()){ min=x; st.push(x); }
  else if (x<min){ st.push(2*x-min); min=x; } else st.push(x); }
pop(){ int t=st.pop(); if (t<min) min = 2*min - t; }
getMin(){ return min; }
