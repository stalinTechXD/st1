🔀 Permutations of a String I — Swapping fix & swap

Generate every arrangement by fixing each position in turn: swap the current index with each later index, recurse, then swap back to restore.

💡 Intuition

Choose who sits here: at index i, try each character from i to the end in that slot (swap it in), recurse on i+1, then swap back (backtrack). When i reaches the end, the string is one permutation. "ABC" → 6 permutations.
for j = i … n−1: swap(i, j)→recurse i+1→swap back

🎰 Permutations of a String II — Used Array build & mark

Build the permutation one character at a time in a separate buffer, tracking which characters are already used with a boolean array.

💡 Intuition

Pick an unused letter: at each depth, loop over all characters; skip the ones marked used, otherwise append it, mark used, recurse, then un-mark (backtrack). When the buffer is full, record it. "ABC" → 6 permutations.
for each char: if used skip→pick, mark used, recurse→un-mark to backtrack

🎭 Permutations of a String III — With Duplicates skip repeats

When characters repeat, naive permutation produces duplicates. Sort first, then skip a character if it equals the previous one that's still unused.

💡 Intuition

Use each duplicate once per level: sort the letters. At each depth skip c[i] if c[i] == c[i−1] and c[i−1] wasn't used at this level — that guarantees each distinct arrangement is generated once. "AAB" → only 3 unique: AAB, ABA, BAA.
sort the characters→skip c[i] if == c[i−1] & prev unused→unique perms only

🐀 Maze Paths (Rat in a Maze) DFS + backtrack

Find a path through a maze from start to goal. Explore a direction; if it leads to a dead end, backtrack (un-mark the cell) and try another.

💡 Intuition

Explore, dead-end, retreat: mark the current cell as part of the path and recurse into open, unvisited neighbours. If none reach the goal, this cell is a dead end — un-mark it and return so a different route can be tried. Watch it enter the top corridor, hit a dead end, and back out.
mark cell & recurse neighbours→reached goal? done·dead end? un-mark & retreat
🔒 Keep forever: "Maze solving = DFS that marks the path and un-marks on dead ends (that un-mark is the backtrack)."

Never forget: mark a cell visited before recursing and unmark after — otherwise you loop or block valid routes.

👑 N-Queens place · check · backtrack

Place N queens on an N×N board so none attack each other. Try each row in the current column; if it's safe place a queen, else backtrack.

💡 Intuition

One queen per column: go column by column. In each column, try each row — if no earlier queen shares that row or diagonal, place it and move to the next column. If a column has no safe row, remove the previous queen and try its next row (backtrack). 4×4 → 2 solutions.
for each row in column→safe? place & next column·stuck? remove & try next row

Never forget: track attacked rows & both diagonals in sets for O(1) safety checks — column index ± row gives the diagonals.

🔢 Sudoku Solver constraint backtracking

Fill each empty cell with a digit that doesn't clash in its row, column, or box. If no digit fits, backtrack and change an earlier choice.

💡 Intuition

Try, validate, retreat: find the next empty cell, try digits 1..N, and keep one only if it's valid in the row, column, and sub-box. Recurse to the next empty cell; if it hits a wall, undo (set the cell back to empty) and try the next digit. Here a 4×4 puzzle solves fully.
next empty cell→try digit if valid→recurse · dead end → erase & retry

🧠
Never forget: choosing the empty cell with the fewest valid options first (MRV heuristic) makes real 9×9 solvers dramatically faster.
