🌳 Introduction & Representation N children

A generic (n-ary) tree lets each node have any number of children — stored as a list, not fixed left/right.

💡 Intuition

A family with many kids: each node holds a value and a list of children. A common flat representation is an Euler array where each number is a node and −1 means "go back up to the parent" — build it with a stack.
number → new node (child of stack top)·push it·−1 → pop
🔒 Keep forever: "Node = value + list of children; −1 in the Euler array means pop up to the parent."

🧭 Rooted vs Unrooted Trees Direction

An unrooted tree is just connected nodes with edges; rooting it picks a top and orients every edge parent → child.

💡 Intuition

Hanging a mobile: an unrooted tree is a set of edges with no "up". Pick any node as the root and let gravity pull the rest down — a BFS/DFS from the root assigns each node its parent and children. The same graph becomes a rooted tree.
edges only (unrooted)→pick a root→BFS orients parent → child
🔒 Keep forever: "Unrooted = edges with no direction; rooting picks a top and orients everything downward."
Rooting the same tree at node 10 — watch the levels fill outward.

🧠
Never forget: the same unrooted tree can be rooted at ANY node — the parent/child relationships change, but the connections don't.
root(start){ visited={start}; parent[start]=null;
  BFS/DFS from start: for each neighbor v: if(!visited) { parent[v]=cur; children[cur].add(v); } }

🚶 Generic Tree Traversal Pre · Post · Level

Preorder visits the node then all children; postorder visits all children then the node; level order goes tier by tier.

💡 Intuition

Node before or after the family: with many children, "inorder" no longer makes sense — but preorder (node, then recurse each child) and postorder (recurse each child, then node) do. Level order uses a queue for a breadth-first sweep.
Pre: node, then children·Post: children, then node·Level: BFS queue
🔒 Keep forever: "Preorder = node first; postorder = node last; level order = queue by depth."
Press play to see all three traversals.
🐢 🐇
🧠
Never forget: recurse over node.children with a for-loop. Preorder & postorder are the workhorses for size, height, and DP.
void pre(Node n){ visit(n); for(Node c : n.children) pre(c); }
void post(Node n){ for(Node c : n.children) post(c); visit(n); }
void level(Node r){ q.offer(r); while(!q.isEmpty()){ Node n=q.poll(); visit(n); for(c) q.offer(c); } }

📏 Diameter & Height I Two deepest children

Height = longest path down. Diameter = longest path between any two nodes, bending through some node's two deepest children.

💡 Intuition

The widest reach: a node's height is 1 + its tallest child's height. The longest path through a node uses its two tallest children: height₁ + height₂ + 2 edges. The diameter is the max of that over all nodes.
height = 1 + max child height·through node = top-2 child heights + 2
🔒 Keep forever: "Diameter bends through a node's two deepest children — sum their heights (+2 edges)."
Press play. Each node tests its two deepest children.
🐢 🐇
🧠
Never forget: for n-ary you need the top-two child heights (not all). Recomputing heights per node is the naive O(n²) route.
int height(Node n){ int h=0; for(c) h=max(h, 1+height(c)); return h; }
// diameter: max over nodes of (h1 + h2) where h1,h2 = top-2 child heights

⚡ Diameter & Height II O(n) single pass

One DFS returns each node's height while updating a global diameter — no repeated height computation.

💡 Intuition

Measure while climbing: as the DFS returns each child's height, keep the largest two seen at the current node. Update the global diameter with their sum, then return this node's height (1 + the largest). One traversal, O(n).
🔒 Keep forever: "Track the top-two child heights on the fly; update diameter, return height. O(n)."
Press play. Heights compute once; the diameter path glows.
🐢 🐇
🧠
Never forget: keep two running maxes (max1, max2) of 1+childHeight; diameter = max(diameter, max1 + max2).
int dfs(Node n){
  int m1=0, m2=0;
  for(Node c : n.children){ int h=1+dfs(c);
    if(h>m1){ m2=m1; m1=h; } else if(h>m2) m2=h; }
  dia = max(dia, m1+m2);
  return m1;
}

🐈 Cats in a Park BFS spread

A cat sits at a spot in a park (tree of paths); it can roam outward one path at a time. How far does it spread, and which spots are within reach?

💡 Intuition

A meow rippling outward: treat the tree as undirected (you can walk to a parent OR a child). BFS from the cat's spot; each ring is one step farther. The farthest ring is the cat's eccentricity — how long until the whole park has heard it.
BFS from the cat's node→neighbors = parent + children→farthest ring = eccentricity
🔒 Keep forever: "In a tree, distance from a node = BFS treating parent & children as neighbours."
The cat starts at node 30. Rings show distance 0, 1, 2, 3.
Press play. The cat's reach ripples through the park.
🐢 🐇
🧠
Never forget: a rooted tree only has child pointers — precompute parents (or build an adjacency list) so BFS can also walk upward.
build adjacency (parent + children);
BFS from cat: dist[cat]=0;
for each popped u, each neighbor v unvisited: dist[v]=dist[u]+1;
eccentricity = max(dist);

🏭 Industries in a Kingdom Subtree DP

A kingdom is a tree of cities, each with some industries. Compute the total industries in every city's subtree — a post-order aggregation.

💡 Intuition

Sum from the bottom up: a city's total = its own industries + the totals of all the cities beneath it. Post-order (children first) lets each city collect its descendants' sums before adding its own. The capital ends up with the grand total.
recurse into children→sum their totals→+ own industries
🔒 Keep forever: "Subtree total = own value + sum of children's subtree totals (post-order)."
Each node shows its own industries; the label above shows its subtree total.
Press play. Totals bubble up to the capital.
🐢 🐇
🧠
Never forget: this "return an aggregate up the tree" pattern (sum, max, count) is the backbone of nearly all tree DP — one post-order pass, O(n).
int subtree(Node n){
  int total = n.industries;
  for(Node c : n.children) total += subtree(c);
  n.total = total; best = max(best, total);
  return total;
}
